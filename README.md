# ars-nova-singers-portal

**Ars Nova Singers — custom WordPress plugin.** Canonical source (private use; not distributed).

- Current version: 1.2.1 (matches DEV arsnovasingers.kinsta.cloud)
- Environment: DEV only; not on LIVE.
- Login-gated members portal for Ars Nova Singers — seasons, projects, materials, roster, calendars, RSVPs, singer bios. DEV v1.2.1.

Releases: each tag v<version> attaches the installable zip (top folder ars-nova-singers-portal/). Install/update via the Ars Nova Ops installer or WP-admin upload.
